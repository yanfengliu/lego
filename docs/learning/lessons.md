# Lessons

The one-line form of every lesson this repo has paid for and not yet turned into a gate. It is a queue, not a destination.

Each rule links into [lessons-evidence.md](lessons-evidence.md), which holds the war story and the anchor. Open that only when a rule is in doubt, or the work is in that area — it is not session-start reading.

A new lesson is an entry there plus one line here, and the line **names the gate it is waiting for**: a test, a lint rule, a schema check, a fixed command. An entry that can name no gate is not a lesson — knowledge with no mechanical trigger is promoted into the fleet constitution through [canon-candidates.md](canon-candidates.md), or into [../policies/local-rules.md](../policies/local-rules.md) when it binds only here, and the rest is folklore and is dropped. Run npm run lessons:check to keep the two halves in step: a rule always has an entry, and an entry always has a rule.

Both halves are deleted in the commit that lands the gate, and deleting them means proving the gate first. [gate-proofs.md](gate-proofs.md) records, for every lesson that left this file that way, the product-code edit that reintroduces the defect and the line the gate printed when it caught it. A gate nobody has watched fail is a claim, not a gate, and nothing leaves on one.

## Rules

- A byte comparison knows only that two files differ; a message naming what changed is a guess, and it prints nonsense exactly when the guess is wrong. **Waiting on:** a regression over the three `--check` messages of `scripts/generated-file-staleness.mjs` asserting that each names the domain values that moved, and says the bytes moved while the meaning did not when none did — the original regression was deleted with the obsolete pinning surface it was written against. ([evidence](lessons-evidence.md#a-byte-comparison-knows-only-that-two-files-differ))
- A fixed crop box silently decapitates the big items — size the crop to its own content. **Waiting on:** a unit test over the inventory-thumbnail content-scan crop, driving a tall part and a short one through the same cell and asserting the tall one is not truncated; the probe it lives in today needs the booklet PDF. ([evidence](lessons-evidence.md#a-fixed-crop-box-silently-decapitates-the-big-items))
- A hand-assembled parts array is not a document: stacking without connection edges validates as a collision. **Waiting on:** a `packages/brick-kernel` unit test that builds the same four on-lattice placements twice — spread straight into `parts`, and through `createPlacePartTransaction` and `applyBuildOperations` — and asserts twelve blocking issues against zero. The anchor is a Playwright spec. ([evidence](lessons-evidence.md#a-hand-assembled-parts-array-is-not-a-document))
- A document's parts are not in insertion order; key a part by the id its command returned, never by array position. **Waiting on:** a `packages/brick-kernel` unit test asserting that `applyBuildOperations` returns a part order that does not track insertion, and that the id `createPlacePartTransaction` returned names the placed part. The anchor is a Playwright spec. ([evidence](lessons-evidence.md#a-documents-parts-are-not-in-insertion-order))
- A panel's own stud grid fits the booklet's camera angles and scale with no part identities; where the model sits is not in the grid. **Waiting on:** a translation-invariance case in `packages/rendering/src/camera-fit-lattice.test.ts` — the same synthetic panel drawn at two origins fits to one basis and one solution — plus an assertion that `StudLatticeFit` carries no field naming a position. The recovery half is already gated there; the "no translation" half is not. ([evidence](lessons-evidence.md#a-panels-own-stud-grid-fits-the-camera-but-not-where-the-model-sits))
- Measure the art you are imitating: booklet parts carry three face tones, a near-black stud wall and a per-colour ink, not one flat fill. **Waiting on:** a unit test over `packages/rendering/src/instruction-finish.ts` pinning the three face tones, the stud-cap-over-wall pair and the per-colour ink against the measured numbers; `apps/web/e2e/instruction-finish.spec.ts` is Playwright and needs the printed reference. ([evidence](lessons-evidence.md#measure-the-art-you-are-imitating-rather-than-asserting-its-dialect-in-a-comment))
- Two consecutive printed panels are one drawing moved: take the scale from the camera fit and search only the shift. **Waiting on:** a case in `apps/web/src/assembly/panel-registration.test.ts` that lets the scale be searched and shows it running to the bottom of its range because the model grows between panels, against the held scale recovering the shift. The anchor drives 50 real panels through Playwright. ([evidence](lessons-evidence.md#two-consecutive-printed-panels-are-one-drawing-moved))
- Matching a gallery one item at a time discards what makes it a gallery: choose once, globally, so taking an entry costs the others. **Waiting on:** a test file for `scripts/part-assignment.mjs` — there is none — driving one synthetic gallery through nearest-match and through the one-to-one assignment and asserting the over-claim falls. ([evidence](lessons-evidence.md#matching-a-gallery-one-item-at-a-time-discards-the-constraint-that-makes-it-a-gallery))
- Elements differing only in colour are one shape twice, so a colour distance softened to the nearest shared tone merges them. **Waiting on:** a test file for `colourDistance` and the `detail` grid in `scripts/part-thumbnail-image.mjs` — there is none — separating a black tile from a white one by mean ink and light face, and merging them under nearest-tone matching. ([evidence](lessons-evidence.md#elements-differing-only-in-colour-are-one-shape-twice))
- An orientation compared as a string, not modulo the part's own symmetry, manufactures false positives. **Waiting on:** nothing new. The gate exists, as the `catalog-part-self-symmetry` rows of "recomputes the retained v8 report and derives the exact step-1 canonical origin" in `apps/web/test/real-build-builder-calibration.test.ts`. That case is red at baseline — the in-flight catalog `/30` change makes its pinned Builder source digests stale — so the mutation proof cannot be run against it. This line leaves the moment that case is green. ([evidence](lessons-evidence.md#an-orientation-compared-as-a-string-not-modulo-the-parts-own-symmetry))
